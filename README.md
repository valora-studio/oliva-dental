# Олива — демо-сайт стоматологии

Демо-сайт вымышленной клиники имплантации и эстетики. Сделан студией [Valora](https://valora-studio.github.io/).
Клиника, врачи, цены, отзывы и контакты вымышлены; изображения и видео сгенерированы нейросетью.

Сцены на первом экране, в кабинете и в блоке «Как планируем» — видеоролики, нарезанные на кадры
и прокручиваемые скроллом на canvas (`js/main.js`). Без сборки: обычные HTML, CSS и JS.

- `tools/make_frames.sh <clip> <name> [кадров ПК] [кадров телефон] [начало] [конец]` — нарезать ролик на кадры
- `python tools/shot.py [ширина] [высота]` — скриншоты в ключевых точках скролла (`out/`)
